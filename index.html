Option 2: Use the High Sierra Patcher as a downloader (no USB needed)

You do not need a USB stick. Your A1286 MacBook Pro supports High Sierra natively, so the patcher is only used to download the official Apple installer to your internal drive.

1. Download the tool

Open Safari on your Mac, go to dosdude1.com/highsierra, and download the macOS High Sierra Patcher.

2. Download High Sierra directly

  • Open the macOS High Sierra Patcher app.
  • In the top menu bar, click Tools → Download macOS High Sierra...
  • Confirm the prompt, and save the downloaded file directly to your /Applications folder.
  • The app fetches the full 5 GB official Apple installer from Apple's servers onto your hard drive.

3. Run the installer

  • When the download reaches 100%, quit the Patcher app. You don't need it to make a USB or apply patches.
  • Open Finder → Applications.
  • Double-click Install macOS High Sierra and follow the prompts to upgrade.

Fallback: Download in Terminal (if the Patcher fails)

Open Terminal and run this command to download the installer:

cd /Applications && curl -O https://updates.cdn-apple.com/2019/cert/061-39476-20191023-48f504f5-60a6-408d-8622-a733cf5062e5/InstallmacOSHighSierra.dmg

Once downloaded, mount the image and unpack it to /Applications:

hdiutil attach InstallmacOSHighSierra.dmg
sudo installer -pkg "/Volumes/Install macOS/InstallOS.pkg" -target /

Then double-click Install macOS High Sierra in your Applications folder to run the upgrade.

Earlier instructions (Option 1: Terminal only)

Step 1: Open Terminal & Fetch the Installer Package

Open Terminal on your MacBook Pro (press Cmd + Space, type Terminal, and hit Enter). Then copy and paste this command:

cd ~/Downloads && curl -O https://updates.cdn-apple.com/2019/cert/061-39476-20191023-48f504f5-60a6-408d-8622-a733cf5062e5/InstallmacOSHighSierra.dmg

Step 2: Mount the DMG Image

Once the download finishes, mount the downloaded image to your filesystem:

hdiutil attach InstallmacOSHighSierra.dmg

Step 3: Extract the Installer to your Applications Folder

Run the installer package inside the DMG to extract the official Install macOS High Sierra app:

sudo installer -pkg "/Volumes/Install macOS/InstallOS.pkg" -target /

(Enter your administrator password when prompted.)

Step 4: Launch the High Sierra Upgrade

Finally, open the installer app to start the upgrade process:

open "/Applications/Install macOS High Sierra.app"

Step 5: Post-Install Update Check (Run After Upgrade Finishes)

Once your Mac finishes upgrading to High Sierra and reboots, open Terminal and run this to pull any remaining security patches:

sudo softwareupdate -i -a

Step 6: Power Saver Settings for Server Use (Optional)

If you plan to run this MacBook Pro headless/lid-closed as your server:

Prevent system sleep when the lid is closed
sudo pmset -a disablesleep 1
Enable auto-restart if power cuts out
sudo pmset -a autorestart 1
Both together
sudo pmset -a disablesleep 1 sudo pmset -a autorestart 1

After the upgrade: print server and home hub

Phase 1: Post-upgrade checks and updates

Go to Apple menu → About This Mac. Check that it shows macOS High Sierra 10.13.6.

Open Terminal and install the remaining updates:

sudo softwareupdate -i -a

Check: run this. It should say "No new software available".

softwareupdate -l

Phase 2: Power and heat settings for server use

The goal is about 5–8 W at idle.

Use the integrated GPU only. Download gfxCardStatus (or the gSwitch fork). Click its menu bar icon and set it to Integrated Only.

Check: the AMD discrete GPU stays off. This saves about 8–12 W and cuts heat.

Keep it running with the lid closed:

sudo pmset -a disablesleep 1 sudo pmset -a autorestart 1

Check: close the lid while on power. The Mac should still answer on the network. From another computer, run:

ping macbook-pro.local

Phase 3: HP P1102w manual duplex printing

Phones and tablets can't handle the "flip the paper and continue" prompt, so the Mac hosts the printer.

  • Plug the HP LaserJet P1102w into the Mac by USB.
  • Go to System Preferences → Printers & Scanners and add the printer. Make sure it uses the HP LaserJet Professional P1102w driver, not Generic PostScript/PCL.
  • Open a document, press Cmd + P, choose Layout / Finishing, and check that Print on Both Sides (Manually) is there.

Check: print a multi-page PDF. The printer prints side 1, the Mac asks you to flip the stack, and side 2 prints after you click Continue.

Share the printer: go to System Preferences → Sharing, tick Printer Sharing, and tick the HP P1102w.

Phase 4: Remote control and server services

Go to System Preferences → Sharing and tick Remote Management (or Screen Sharing) and Remote Login.

Check: from your phone, iPad, or another laptop, connect with SSH (change username to your Mac username):

ssh username@macbook-pro.local

Home hub automations: run scripts natively with a local Node runtime, or use a small Linux setup (Docker, Multipass, or dual-boot) if you need Linux-only apps.
